# Daft-Punk-Helmet
A little Daft Punk Helmet build that I made as my first big personal project.
I planned on making this project for ~2 years before I actually started, due mainly to a lack of resources and knowledge.
The print files and most of the code were taken from JordyM on Thingiverse (https://www.thingiverse.com/thing:3385744).
I designed the wiring of the LED matrix to be compatible with his code since no wiring diagram was provided. I also altered the code to display what I wanted instead of the preset designs that came with Jordy's code.
I plan on swapping out the Arduino Nano with an ESP32 and redoing the code at some point so that I'll be able to change what the helmet is displaying from my phone. But to be honest, I'm probably going to wait until after Halloween to do that :).
